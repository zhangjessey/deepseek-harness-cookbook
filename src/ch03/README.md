# 第 03 章｜事件系统：五种分发模式及其适用场景

## 文件说明

| 文件            | 说明                                                              |
| --------------- | ----------------------------------------------------------------- |
| `five-modes.ts` | 五种分发模式逐个演示：emit / parallel / serial / bail / waterfall |

## 运行示例

确保已经执行过 `npm install --legacy-peer-deps`，然后在**项目根目录**运行：

```bash
npm run start:ch03
```

## 预期输出

```text
=== emit：广播一条消息，所有监听器都收到 ===
  [日志插件] 记录消息： 你好，Cordis
  [统计插件] 消息字数： 9

=== parallel：多个耗时任务并发执行 ===
  [任务 A] 完成： 并行任务
  [任务 B] 完成： 并行任务
  （两个任务并发完成，总耗时约 100ms 而非 200ms）

=== serial：依次询问「谁能处理」，第一个能处理的胜出 ===
  识别到的意图： weather

=== bail：同步地找第一个能回答的监听器 ===
  同步识别到的意图： time

=== waterfall：对回复文本层层加工 ===
  正常回复： 【bot】你好，很高兴见到你
  被拦截的回复： 【bot】（内容已拦截）

=== 收尾 ===
demo 已退出
```
